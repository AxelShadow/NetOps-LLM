# NetOps-LLM — инфраструктурный ассистент

Задавайте вопросы об инфраструктуре: состояние устройств, диагностика,
инвентарь. Ассистент выполняет действия по шагам — каждый запуск
инструмента показывается отдельной карточкой (✔ — успех, ✖ — ошибка).

- Отвечайте в том же диалоге, чтобы ассистент помнил контекст.
- Если сервис временно недоступен, сообщение сохранится — просто
  продолжите позже.
