# Runbook'и NetOps (корпус для RAG)

Каталог с внутренними инструкциями и регламентами, по которым отвечает
агент (инструмент `search_internal_docs`). Документы индексируются в Qdrant;
ответ агента ссылается на путь документа (например, `network/example-runbook.md`).

## Что попадёт в индекс

* расширения `.md`, `.markdown`, `.txt`; подкаталоги обходятся рекурсивно;
* размер файла — не больше 1 МиБ (`NETOPS_RAG_MAX_FILE_BYTES`), крупные
  файлы пропускаются с записью в список ошибок индексации;
* текст режется на чанки по разделам Markdown: до 1200 символов,
  перекрытие 150 (`NETOPS_RAG_CHUNK_CHARS` / `NETOPS_RAG_CHUNK_OVERLAP`);
* путь документа хранится относительно `NETOPS_RAG_DOCS_DIR`; `..` и
  симлинки за пределы каталога игнорируются;
* индексация инкрементальная по sha256: неизменённые файлы не пересчитываются,
  удалённые — вычищаются из индекса.

Всё остальное (`.pdf`, `.docx`, изображения, бинарники) не индексируется —
конвертируйте в Markdown/plain text до копирования в каталог.

## Формат документа

Заголовки Markdown — это и есть структура: путь заголовков
(`Раздел > Подраздел`) попадает в метаданные чанка, поэтому по нему удобно
искать. Рекомендуется:

* `#` — один на документ, название процедуры («Перезапуск сервиса
  визуализации»), без дат в заголовке. Исключение — учебный
  `example-runbook.md`: в нём три независимых примера, каждый со своим `#`
  (заголовок того же/высшего уровня начинает новый путь заголовков);
* `##` — этапы и темы («Когда применять», «Проверка», «Откат»);
* `###` — отдельные команды/шаги, если их нужно искать по отдельности;
* одна тема — один файл; не смешивайте несвязанные процедуры.

Шаблон-образец с вымышленными примерами: [example-runbook.md](example-runbook.md).
Он нужен для dev-стенда и проверки поиска; на проде заменяется реальными
runbook'ами (файл можно удалить).

## Как добавить или обновить

1. Положите файл в `runbooks/` (можно в подкаталог — путь станет частью
   `source`). В docker-compose каталог монтируется в контейнер как
   `/data/runbooks:ro`, поэтому правки на хосте видны без пересборки образа.
2. Запустите переиндексацию (см. ниже) — иначе поиск не увидит новые чанки.
3. Проверьте в чате: «что написано в инструкции про …» — агент должен
   вызвать `search_internal_docs` и сослаться на путь файла.

## Переиндексация

Инкрементальная (по умолчанию) переиндексирует только изменённые файлы;
принудительная (`force`) пересчитывает всё заново.

**В админке** (`/admin/settings`, секция «RAG по runbook'ам», только admin):
статус (`enabled`, каталог, число документов/чанков, время последней
индексации, доступность Qdrant, модель эмбеддингов, ошибка) и кнопка
«Переиндексировать» (`POST /admin/settings/rag/reindex`).

**Из контейнера** (работает и без UI; образ содержит пакет `app`, поэтому
используются вызовы функций, а не CLI-скрипт — его в образ не копируют):

```bash
# статус индекса
docker compose exec app python -c "from app.rag.service import get_status; print(get_status())"
# переиндексация (force=True — пересчитать все файлы заново)
docker compose exec app python -c "from app.rag.service import reindex_documents; print(reindex_documents(force=True))"
```

**На хосте с checkout** (из `backend/`, интерпретатор `backend/.venv`):

```bash
cd backend
.\.venv\Scripts\python.exe reindex_rag.py            # инкрементально
.\.venv\Scripts\python.exe reindex_rag.py --force    # всё заново
.\.venv\Scripts\python.exe reindex_rag.py --status   # только статус
```

Проверка, что Qdrant доступен приложению (порт наружу не пробрасывается):

```bash
docker compose exec app python -c "import httpx; print(httpx.get('http://qdrant:6333/readyz', timeout=5).status_code)"
```

## Правила содержимого (обязательно)

* **Секретов нет.** Пароли, токены, ключи, SNMP-community, учётные записи —
  только отсылка к менеджеру секретов/заявке, без значений.
* **Внутренние данные не для внешних каналов.** Адреса, FQDN и топология
  остаются внутри; для примеров в документации используйте вымышленные
  имена и диапазоны из RFC 5737 (`192.0.2.0/24`, `198.51.100.0/24`,
  `203.0.113.0/24`).
* **Не дампите конфиги целиком**: фрагмент конфига без учётных данных,
  остальное — ссылкой на место хранения.
* Перед коммитом: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .dsh\tools\secret-scan.ps1 -Mode quick`.
