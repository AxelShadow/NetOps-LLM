Утренний отчёт

Ежедневное письмо с состоянием инфраструктуры (Zabbix + инвентарь). Параметры применяются без перезапуска сервера.

Формат HH:MM, таймзона сервиса

Через запятую/точку с запятой, максимум {{ recipients_max }} адресов.

SMTP (Zimbra)

Только имя хоста/IP: без схемы и порта (порт — отдельное поле).

Внимание: без TLS (none) учётная запись SMTP запрещена — допустимо только для loopback-адреса (например, localhost).

Доступные переменные: date, total_active_devices, zabbix_alerts, critical, warning, new_problems_count, resolved_count, datastore_low_space, host_high_load, vms_with_snapshots, problems_text, summary_text.
